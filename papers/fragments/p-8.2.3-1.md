In the Paxos family the configuration itself is replicated consensus state: Lamport, Malkhi and Zhou define a reconfigurable state machine whose configuration is a state component changed only by an executed reconfiguration command~\cite{reconfig-sm}, and Vertical Paxos instead commits each new configuration to an auxiliary configuration master, which determines the set of acceptors of every configuration~\cite{vertical-paxos}. This design keeps that commitment inside the application: reconfiguration batches commit in the same slot stream as client values.
