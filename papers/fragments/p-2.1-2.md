A node identity is universally unique and never recycled, and it is durable before any startup emission. This is the obligation Paxos places on proposal numbers~\cite{pms}, applied to node identity: a bump assigns a value that no life of any node has used or will use. The boot marker carries the identity as the durable pair \{system identifier, counter\}, the packing of a unique per-processor identifier with an increasing counter that Disk Paxos describes for ballot numbers~\cite{diskpaxos}. The identity write is amortised into the single small boot-fence write of the following paragraph, so no flush is added to any critical path.
