# research/literature/turner — working rules

## The bibliography is Zotero-synced; never hand-edit it

`paxos-reconf-latest.bib` in this directory is a Zotero export. It is synced
from the user's Zotero library; the copy under `../uvrr-core` is the managed
one and this copy tracks it.

- Do NOT edit the `.bib` by hand. Any hand edit is wiped by the next sync.
- If a citation is missing, wrong, or incomplete, the change is made in Zotero
  and the file is re-synced. An agent that finds such a problem does not patch
  the file: it raises a GitHub issue titled `docs: citations <what is wrong>`
  as the tracker, and says in its report that the bib is Zotero-managed.
- Papers fetched for reading (PDF, extracted text) are research artefacts and
  follow the usual research conventions; the `.bib` alone is the synced file.
