[lab 1]
Lab book, the arithmetic of a promise. Everything in this development reduces to these three definitions. A configuration is a weight function; a quorum is a set whose weight beats half the total. No sets are enumerated anywhere — a quorum system is a predicate, and ‘is a quorum’ is arithmetic.

[lab 2]
Turner's Lemma 2, mechanised. If two configurations are at scaled distance at most one — the per-node mass they move, measured against common factors, is a single unit — then their strict-majority families frown: every quorum of one meets every quorum of the other. This one lemma carries every era boundary in the reincarnation schedules.

[lab 3]
The only configuration assumption. Turner's P1: at every era e, the phase-II family of e frowns the phase-I family of e, which frowns the phase-II family of e+1. Nothing else about configurations is assumed anywhere in the agreement proof.

[lab 5]
The casting vote. When the old quorum and the new quorum meet in exactly one node — the leader — that node's vote decides the boundary. Turner uses this to cross a reconfiguration while the victim's vote is missing presumed dead; the three-node reincarnation's first boundary is exactly this shape.

[lab 8]
Amnesia is unreachable. Not ‘handled’, not ‘recovered’: unreachable. Once the machine is in the bumped phase, no continuation of it ever runs under the pre-bump identity again. This is the formal content of ‘crash-recover is unrepresentable’ — and it is where the DISC'17 bug class dies.

[lab 11]
The Telescoping Theorem. One response set acknowledges the whole batch; if it is a quorum at the first transition and eligibility is preserved at each step, it is a quorum at every transition of the schedule. Lamport ran the same induction in Paxos Made Simple §2.5 — ‘using the same proposal number for all instances’. Here it is kernel-checked, with the preservation hypothesis explicit.

[lab 12]
The negative control that earns the hypothesis. The equal-total swap (1,2,1,2)→(2,1,2,1): the response set {B,D} is a majority before and a minority after.
